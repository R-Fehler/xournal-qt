# Test font

`RegionalLetters.ttf` ("Xqt Test Regional Letters"): DejaVu Sans 2.37 cut down to the letter "A", which it also
shows for the regional indicators U+1F1E6–1F1FF (the halves of flags), made with fontTools for
`EmojiFontTest.cpp`. It stands for a system font such as Android's Noto Sans Symbols, which draws flags as boxed
letters. Bitstream Vera license (`qt/resources/fonts/LICENSE-DejaVu.txt`), renamed as it asks of modified fonts.
