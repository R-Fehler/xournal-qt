Draft notes for the next pre-release of **xournal-qt** (not released yet; the version is set when it is cut).

## Changes

- **Handwriting at an angle is read as well as level handwriting**: a line turned by 90° (a note up or down the
  margin) is now found whole and read exactly as the same ink level; before, real handwriting at 90° fell apart into
  several pieces, most of them read as level text (about a fifth of the letters wrong). Also new: text written
  **upside down** (leftwards, 160°–180°) and leftwards at a slant (110°–160°) is read upright, a long line written
  **uphill at 10°–20°** keeps its own angle instead of being cut into pieces, and a **margin note of two words** is
  enough. Measured on the handwriting benchmark with the built-in model: at ±90° and 180° the same reading as level;
  at 15°–45° and ±135° one line per line with about 11–13 % of the letters read differently (before: 2–18 pieces per
  line, up to 85 % different).
