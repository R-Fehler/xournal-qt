Draft notes for the next pre-release of **xournal-qt** (not released yet; the version is set when it is cut).

## Changes

- **Handwriting at an angle is searchable**: notes written upwards or downwards along a margin or a slide's edge, a
  label along an arrow, a line written steeply uphill are found by the search, marked over the ink (turned with it),
  copied as text (as a line of their own) and put into the invisible text layer of PDFs with notes, turned with the
  ink so other viewers select along it. Level handwriting is read exactly as before. Not yet: text written leftwards
  (upside down); a column of single letters may be taken for a line written downwards.
