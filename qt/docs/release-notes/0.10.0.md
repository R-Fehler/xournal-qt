Draft notes for the next pre-release of **xournal-qt** (not released yet; the version is set when it is cut).

## Changes

- **Pinching no longer turns the canvas by accident**: two fingers turn it only after a deliberate twist of about
  65° (a large pinch twists the fingers a little on its own). Once it turns, it follows the fingers, also back to
  smaller angles, and still snaps to 0°, 90°, 180° and 270°. The touchpad's rotate gesture is unchanged.

## Fixed

- **Pasted text is readable again**: text pasted onto a page (handwriting copied as text, or text from another app)
  takes the text tool's color. It took the color of the tool in hand, so with the lasso of "Copy as text" it could be
  white, and with the highlighter yellow.
