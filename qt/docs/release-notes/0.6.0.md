Draft notes for the next pre-release of **xournal-qt** (not released yet; the version is set when it is cut).

## Replay how a document was written

- **The timeline**: ⋮ → View → Replay (or the replay button of the playback pill) shows a play bar at the bottom and
  replays the document as it was written, stroke by stroke, read-only: play and pause, scrub, speed, jump between
  sessions (a long pause starts a new one; shorter pauses are shortened). Recordings play along where they overlap
  the writing, so a lecture's ink appears as it was said. Tap a stroke to jump there. Leaving it leaves the document
  exactly as it was.
- Every new stroke, text, image and link now carries the time it was made (about 5 bytes per stroke in the file; a
  `xqt-created` attribute that Xournal++ ignores). Older documents and files saved by Xournal++ have no times: their
  ink comes first, in the order it lies on the page.
- Not yet: erasing, moving and page changes are not replayed (strokes appear where they are now); a stroke is drawn
  on at an even pace, not at the speed it was written.

## Versions inside the PDF

- **Version history** for PDFs with notes (off by default; switch it on in the sidebar's History tab, ⋮ → Document →
  Version history…, or for every new PDF with notes in Settings → Documents). The file keeps one version per day you
  worked on it, plus **milestones**: Ctrl+Alt+S (Save with a message…) keeps a version with your message for good.
  The PDF as you received it is the first version.
- **Look back**: the History panel lists the versions (milestones only, if you like) and how much room they take; a
  version opens read-only beside the document, can be restored (as a new version on top, one undo step) or opened as
  a copy.
- **Still one ordinary PDF**: the versions are the PDF's own incremental updates. Every PDF app shows the latest one,
  and the latest notes are a plain `document.xopp` attachment any PDF tool can extract; older versions are stored as
  small deltas (`xournal-qt-cli export-xopp file.pdf --version N` gets any of them back).
- **Sharing** sends a copy without the versions unless you tick "With its version history". Documents that keep
  versions show a clock on their library card.
- Not yet: comparing two versions and playing through them; thinning old versions out (all are kept).
