Third alpha of **xournal-qt**, a Qt 6 fork of Xournal++ for pen tablets and convertibles. This one is about writing:
Markdown grows into a real document format (formulas, pictures, a formatting bar, text documents that are PDFs),
and notes get sticky notes, an annotations overview and space beside slides.

## Markdown

- **Formulas**: `$…$` and `$$…$$` are drawn with MicroTeX (bundled, no LaTeX needed), as vectors on screen and in
  PDFs. `\( … \)` and `\[ … \]`, as ChatGPT and other chat apps write them, work too, and pasting converts them to
  `$…$` so the file stays readable in Obsidian and on GitHub.
- **Pictures**: paste, drop or pick an image and it is saved in `name.assets/` next to the `.md` and linked; the
  library keeps a `.md` and its pictures together (one card; rename, move, trash and share take both). Web pictures
  load only when asked.
- **Formatting bar** for everyone who does not want to type Markdown: headings, bold, italic, lists, check boxes,
  quotes, code blocks, links, formulas, pictures, page breaks, and a **table editor** that works like a small
  spreadsheet.
- **Emoji**: 😄 in colour everywhere (a bundled font, sharp in PDFs), `:smile:` shortcodes with suggestions while
  typing, and a picker.
- Markdown boxes and the page's text are always written on the page, formatted while typing; their source beside
  the page is in the writing button's menu. The old word-processor **text mode is retired** (text written with it
  stays and can still be edited).

## PDFs with notes

- **Text documents as PDF**: with "PDF files" as the way you keep documents, a new text document is a PDF that any
  viewer shows, with its Markdown inside (`name.md`, and its pictures) so it can go back to Markdown editors
  (`qt/docs/user/markdown-from-pdf.md`). "Export as Markdown" and "Open as PDF document" convert both ways; existing
  `.md` files are never converted.
- **Space for notes beside slides**: enlarge pages by any amount on any side (this page, selected pages, or all),
  with the slide kept in place, still searchable, and exported as a larger PDF page.
- The library tells the kinds of PDFs apart: "PDF", "PDF ✎" (with notes) and "PDF MD" (a text document), and can
  show only those with notes or only text documents, now without slowing the listing down.

## Studying

- **Sticky notes**: opaque notes you write and type on, move, resize and colour; **cover mode** hides what is under
  them until you tap (self-testing). Copy, cut and paste them (Ctrl+C/X/V), or drag them onto another page.
- **Annotations panel**: every highlight, comment, text box, sticky note and piece of handwriting of a document, by
  page, with a picture of the page under the ink and the words it marks; "Export as Markdown" makes a summary with
  links back to each place.
- **The same document beside itself**: open the reference view on the document you are in, at the page you choose
  (a figure or the bibliography next to the text).
- **Citations**: look up selected text in Google Scholar or a translator (the web address is shown first); select a
  bibliography entry and find the paper in your library by its title, or import it from arXiv, named by its title.
  Network access is opt-in.

## Everyday

- **Links with the mouse**: a click follows a link with any tool (Ctrl+click while writing text), and hovering a link
  shows where it leads at the bottom, like a browser.
- **Screen calibration**: Settings → Display, hold a ruler to the screen; then 100 % is real size (Ctrl+1).
- **Middle click** fits the page with the mouse, as a double tap does with a finger.
- **Presenting without controls**: Ctrl+F5 (or a long press on the present button) shows only the slide; a faint dot
  in the lower-left corner brings the controls back.
- Fixes: a memory overshoot when switching between tabs and the reference view; a text box drawn over a Markdown
  box's last line in PDFs; pictures of `.md` files with blanks in their names.

## Getting it

Linux: two `.deb` packages (KDE neon / Ubuntu 22.04, and Debian 13 / Ubuntu 25.04 and newer) and an AppImage; which
one fits is in `qt/docs/releasing.md`. Android (arm64) and Windows builds exist and are being tested on devices;
they are not part of this release yet.

## Known limits

- Pictures in `.xopp` Markdown boxes are dropped when the file is saved by Xournal++; sticky notes cannot be pasted
  into Xournal++.
- Handwriting is not searchable yet (research done, see `qt/docs/research/handwriting-recognition.md`).
- Audio recording, the plugin console and the LaTeX tool of Xournal++ are not ported.
