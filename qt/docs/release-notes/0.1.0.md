First release of **xournal-qt**, a Qt 6 fork of Xournal++ for pen tablets and convertibles: the same documents and the
same core, a new interface built for writing with a pen and a finger.

Its files are Xournal++ files. A document written here opens in Xournal++ and the other way round.

## Writing

- Pen, finger and mouse are told apart: the pen writes while the hand rests on the screen (palm rejection with the
  pen's height where the tablet reports it), a finger scrolls and zooms, and the pen's side buttons erase.
- Tools: pen (five widths, the fifth adjustable), highlighter, eraser (with its options on a long press), text,
  selection (rectangle, lasso, tap), shapes, and the setsquare and compass.
- A movable pill in full screen holds the colours, the width, undo and redo.
- Text mode with a panel beside the page, and text that flows over the pages.
- **Markdown boxes**: write Markdown onto a page and see it formatted as you type, in a box anywhere on the page or as
  the page's text, which flows onto the next pages. Headings become chapters in the contents, the search finds the
  text where it is drawn, and code blocks are highlighted. Stored as ordinary Xournal++ text, so Xournal++ shows the
  source (`qt/docs/markdown-boxes.md`).

## Documents

- Tabs, a grid overview of the open documents, and windows a tab can be dragged into.
- A page sidebar and a zoomable grid of all pages, with page operations (copy, move, insert, delete, drag and drop).
- Layouts: one page, two pages, N columns, book.
- A library of folders with previews, a search over the names and the text of every document, and one over all open
  documents. Documents remember where they were left off and which page is their title page.
- PDFs: annotate, text selection and highlighting, links, the PDF's own contents, printing and export (also from the
  command line).
- Contents of its own: chapters and sections for documents without a PDF outline.

## Speed

- Rendered pages are kept within a memory limit (Settings → Documents → Memory; a quarter of the RAM by default) and
  pages are rendered ahead of where you read, so scrolling shows them at once.
- Every page of every open document gets a small preview in the background; the sidebar, the grid and the overview
  show it immediately and the sharp picture follows. Previews are stored in the cache, so a document opened before
  shows all its pages at once (a 179-page PDF: 0.4 s instead of 5 s).
- `XQT_PERF=1` writes a line a second about the canvas work (`qt/docs/testing/performance-logging.md`).

## Getting it

Linux only for now. Which package fits which system is in `qt/docs/releasing.md`; Qt 6.5 or newer is needed.

## Known limits

- Images, math and flattening into text mode are not there yet for Markdown boxes.
- Audio recording, the plugin console and the LaTeX tool of Xournal++ are not ported.
- Windows and macOS need their dependencies and packaging set up (see `qt/docs/releasing.md`).
