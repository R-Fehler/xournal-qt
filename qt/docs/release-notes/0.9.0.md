Ninth alpha of **xournal-qt**, a Qt 6 fork of Xournal++ for pen tablets and convertibles. This one is mostly
**under the hood**: the code was reviewed and reworked to be easier to change, and the review, a ThreadSanitizer run
and runs on newer Qt versions found bugs that are fixed here. On top: **Esc and Android's Back** step out of things
in one order, you can **zoom out further**, and the **English handwriting model downloads from Settings**. It is a
pre-release: see "Known limits".

## Esc and Back

- **Esc steps out of one thing at a time**: close the drawer, hide the curtain's handles, unselect (also selected
  PDF text), put the snip or the to-do stamp away, end the replay, end presenting, leave Zen, leave full screen; the
  next Esc the next one. **Fixed**: Esc did nothing in full screen or while presenting when something else wanted it
  too (a selected sticky note, an armed snip, the to-do stamp, the replay).
- **Android's back button and gesture** step out of things in the same order; with nothing left, they ask "Leave
  Xournal Qt?" before the app is left.

## Zoom, shortcuts, handwriting

- **Zoom out further, and choose how far**: Settings → Display → Zoom → "Smallest zoom" (5–50 % of the real size,
  20 % by default; it was a fixed 30 %). Whatever it is set to, you can always zoom out far enough to see a whole row
  of pages, so two A4 pages side by side fit on an unfolded phone like the Galaxy Fold.
- **Recording has a shortcut you can change** (Ctrl+Shift+R, Settings → Shortcuts), and the tips and menus name the
  keys as you set them instead of the default keys.
- **The English handwriting model downloads from Settings** (Settings → Search → handwriting): about 64 MB from
  Hugging Face, checked against the sizes and checksums this version names. Before, it had to be installed with a
  script. The German model follows once it is trained.

- **Handwriting at an angle is searchable**: notes written upwards or downwards along a margin or a slide's edge, a
  label along an arrow, a line written steeply uphill are found by the search, marked over the ink (turned with it),
  copied as text (as a line of their own) and put into the invisible text layer of PDFs with notes, turned with the
  ink so other viewers select along it. Level handwriting is read exactly as before. Not yet: text written leftwards
  (upside down); a column of single letters may be taken for a line written downwards.

## Saving and writing files

- **Tags and saves of the same PDF no longer get in each other's way**: a Ctrl+S right after giving a PDF tags waits
  for them instead of failing or losing them, and on a PDF with notes that keeps its versions the tags no longer show
  up as a change "by another app" (which stopped "Save with a message" and the day's version from being replaced).
- **Changing a version's message no longer holds up the pen** (version history → a row's menu → "Change the
  message…"): it is written in the background after any save that runs, instead of being refused while one runs.
- **A link updated after a rename and a to-do ticked from the library wait for a save of the same file**, and the
  reverse, so neither is written over the other.
- **Saving a PDF in full now flushes it to the storage before it replaces the file**, as incremental saves already
  did; a `.xopp` with an attached PDF no longer holds up the pen while that PDF is written next to it.

## Fixed

- **Back did nothing in a document with Qt 6.11**, the Qt the Android app is built with (two shortcuts claimed the
  Back key, so neither ran). Found before release, by running the tests on Qt 6.11.
- **Memory errors found by a ThreadSanitizer run**: quitting right after closing a window of its own (an undocked
  document) could crash; the laser pointer's ink read freed memory as it faded; a page that grew while it was drawn
  could be drawn at a mixed size; renumbering page links raced with the drawing; a text opened for editing raced with
  the drawing; and PDFs were written with a file ID made from freed memory.
- **A page could be drawn without its PDF** when the document's PDF was replaced (a reload, pasted PDF pages joining
  it) while pages were being drawn. Old PDF caches of an open tab are now freed instead of kept until it closes.
- **The reference view copied the text of a PDF whose author does not allow copying it** (from its pill and with
  Ctrl+C); it is refused there too now, as it was on the notes.
- **Quitting while pictures are still being drawn is safe**: the page sidebar's thumbnails, the page sketches and the
  annotation pictures now stop with the library's pictures before the app closes, and no page picture is written to
  the cache after that.
- **Flinging through the library no longer loads every document it passes**: a card that scrolled away before its
  picture was drawn is skipped. All these pictures (thumbnails, sketches, cards, search pages) are drawn at idle
  priority, after the pages on the canvas.

## What is not carried over

xournal-qt is in alpha, and the code that converted data of earlier pre-releases is gone.

- **Coming from 0.8.0**: each library reads all its documents once more when it is first opened (its search cache is
  rebuilt; the previews stay), and keys you chose yourself for **Read** are back at Ctrl+Alt+R.
- **Reading positions and stars of documents outside a library** are now kept in the config folder
  (`~/.config/xournal-qt/documents/pages.json`) instead of the cache, so cleaning the caches keeps them. Those kept
  by earlier pre-releases are not taken over.
- **From 0.7.0 or earlier also**: the toolbox starts with its first tools (your tool arrangement and the tools of the
  classic tool bar are not taken over) and a tiny window's reader chrome choice is not read. A PDF with notes written
  before the layer record existed is written in full at its first save, then appended to as usual.
- **The text tool always writes Markdown** text boxes. Ordinary text boxes of Xournal++ files are shown, exported and
  edited as they are; new ones are no longer made. The word-processor text mode (retired in 0.3.0) is gone; its text
  on existing pages stays ordinary text.
- Xournal++ files (`.xopp`, `.xoj`), its settings file and other apps' PDFs are read as before.

## Known limits

- **Tested off-screen only**: Android's back button and gesture (including "Leave Xournal Qt?") and Zen on the phone
  and the Fold have been tested off-screen, on Qt 6.11 as the APK uses, not yet on a device. See the device
  checklist (`qt/docs/testing/device-checklist.md`).
- **Android: the top bar scrolls into a blank area at its end** (from 0.8.0, not fixed yet).
- The plain autosave still runs on the UI thread; a very large document may pause the pen for a moment when it is
  autosaved.
- Handwriting is read in English only until the German model is trained and published.
- From before: comparing versions shows which pages changed, not yet what changed on them; old versions are never
  thinned out; replay shows ink appearing, not erasing or moving it.
