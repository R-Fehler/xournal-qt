Draft notes for the next pre-release of **xournal-qt** (not released yet; the version is set when it is cut).

## Changes

- **Zoom out further, and choose how far**: Settings → Display → Zoom → "Smallest zoom" (5–50 % of the real size,
  20 % by default; it was a fixed 30 %). Whatever it is set to, you can always zoom out far enough to see a whole row
  of pages, so two A4 pages side by side fit on an unfolded phone like the Galaxy Fold.
