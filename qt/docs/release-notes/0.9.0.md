Draft notes for the next pre-release of **xournal-qt** (not released yet; the version is set when it is cut).

## Changes

- **Zoom out further, and choose how far**: Settings → Display → Zoom → "Smallest zoom" (5–50 % of the real size,
  20 % by default; it was a fixed 30 %). Whatever it is set to, you can always zoom out far enough to see a whole row
  of pages, so two A4 pages side by side fit on an unfolded phone like the Galaxy Fold.
- **Settings, caches and the toolbox of earlier pre-releases are not carried over** (xournal-qt is in alpha; the code
  that converted them is gone). Coming from 0.8.0: each library reads all its documents once more when it is first
  opened (its search cache is rebuilt; the previews stay), and keys you chose yourself for **Read** are back at
  Ctrl+Alt+R. From 0.7.0 or earlier also: the toolbox starts with its first tools (your tool arrangement and the tools
  of the classic tool bar are not taken over) and a tiny window's reader chrome choice is not read. A PDF with notes
  written before the layer record existed is written in full at its first save, then appended to as usual. Xournal++
  files (`.xopp`, `.xoj`), its settings file and other apps' PDFs are read as before.
- **Reading positions and stars of documents outside a library are no longer cache**: they are kept in the config
  folder (`~/.config/xournal-qt/documents/pages.json`), so cleaning the caches keeps them. Those kept by earlier
  pre-releases are not taken over.
- **The text tool always writes Markdown** text boxes. Ordinary text boxes of Xournal++ files are shown, exported and
  edited as they are; new ones are no longer made. The word-processor text mode (retired in 0.3.0) is gone;
  its text on existing pages stays ordinary text.
- **Fixed: Esc did nothing** in full screen or while presenting when something else wanted it too (a selected
  sticky note, an armed snip, the to-do stamp, the replay). Esc now always does the first of: close the drawer, hide
  the curtain's handles, unselect, put the snip or the stamp away, end the replay, end presenting, leave Zen, leave
  full screen; the next Esc the next one. It now also unselects selected PDF text.
- **Recording has a shortcut you can change** (Ctrl+Shift+R, Settings → Shortcuts), and the tips and menus name the
  keys as you set them instead of the default keys.
- **Fixed: a page could be drawn without its PDF** when the document's PDF was replaced (a reload, pasted PDF pages
  joining it) while pages were being drawn. Old PDF caches of an open tab are now freed instead of kept until it closes.

- **Tags and saves of the same PDF no longer get in each other's way**: a Ctrl+S right after giving a PDF tags waits
  for them instead of failing or losing them, and on a PDF with notes that keeps its versions the tags no longer show
  up as a change "by another app" (which stopped "Save with a message" and the day's version from being replaced).
- **Saving a PDF in full now flushes it to the storage before it replaces the file**, as incremental saves already
  did; a `.xopp` with an attached PDF no longer holds up the pen while that PDF is written next to it.
- **Quitting while pictures are still being drawn is safe**: the page sidebar's thumbnails, the page sketches and the
  annotation pictures now stop with the library's pictures before the app closes, and no page picture is written to
  the cache after that.
- **Flinging through the library no longer loads every document it passes**: a card that scrolled away before its
  picture was drawn is skipped. All these pictures (thumbnails, sketches, cards, search pages) are drawn at idle
  priority, after the pages on the canvas.
- **Changing a version's message no longer holds up the pen** (version history → a row's menu → "Change the
  message…"): it is written in the background after any save that runs, instead of being refused while one runs. A
  link updated after a rename and a to-do ticked from the library wait for a save of the same file, and the reverse,
  so neither is written over the other.
- **Android's back button and gesture** now step out of things in the same order as Esc: a selection, an armed snip
  or to-do stamp, the replay, presenting, Zen, full screen; with nothing left, it asks "Leave Xournal Qt?" before the app is left.

- **Fixed: the reference view copied the text of a PDF whose author does not allow copying it** (from its pill and
  with Ctrl+C); it is refused there too now, as it was on the notes.

- **The English handwriting model downloads from Settings** (Settings → Search → handwriting): about 64 MB from
  Hugging Face, checked against the sizes and checksums this version names. Before, it had to be installed with a
  script. The German model follows once it is trained.

- **Fixed: memory errors found by a ThreadSanitizer run**: quitting right after closing a window of its own (an
  undocked document) could crash; the laser pointer's ink read freed memory as it faded; a page that grew while it was
  drawn could be drawn at a mixed size; renumbering page links raced with the drawing; and PDFs were written with a
  file ID made from freed memory.
